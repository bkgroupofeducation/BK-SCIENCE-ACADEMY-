# BK Science Academy - Full Stack Application

This repository contains the complete source code for the BK Science Academy website, featuring a React frontend and a Node.js/Express backend.

## 🚀 Project Overview

The platform provides features for student registration, fee payments, scholarship applications, and a support ticket system integrated with an AI Chatbot.

### Key Features:
- **Student Portal**: Admission forms, registration, and scholarship applications.
- **Payment Integration**: Secure fee payment portal using Razorpay.
- **AI Chatbot**: Intelligent assistant for student inquiries and support ticket generation.
- **Admin Panel**: Comprehensive dashboard for managing admissions, enquiries, and student support.
- **Academics**: Dedicated sections for JEE, NEET, and Foundation courses.

## 🛠️ Tech Stack

- **Frontend**: React.js, Vite, Tailwind CSS, Framer Motion, GSAP.
- **Backend**: Node.js, Express.js.
- **Database**: MongoDB (Mongoose).
- **Other**: Razorpay (Payments), Lucide React (Icons).

## 📂 Directory Structure

- `/frontend`: React application (Vite).
- `/backend`: Node.js API server.

## 🚦 Getting Started

### Prerequisites:
- Node.js (v18+)
- MongoDB (Local or Atlas)

### Setup Backend:
1. Navigate to `/backend`
2. Install dependencies: `npm install`
3. Create a `.env` file based on the environment variables needed.
4. Start the server: `npm run dev`

### Setup Frontend:
1. Navigate to `/frontend`
2. Install dependencies: `npm install`
3. Create a `.env` file with `VITE_API_URL`.
4. Start the development server: `npm run dev`
